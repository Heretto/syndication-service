# Administration {#c_administration .concept}

The Administration page lets organization administrators manage their organization's name, members, and pending invitations.

The **Administration** page is visible only to users with the Admin or System Administrator role. Click **Administration** in the navigation menu to open it.

## Organization name {#section_org_name .section}

The organization name is displayed at the top of the page. To change it, edit the name field and save your changes. The name is used for display purposes within the application.

## Members {#section_members .section}

The members table lists every user who has accepted an invitation to join your organization. Each row shows the member's email address and their current role. Two roles are available:

Admin
:   Can access the Administration page, manage members and invitations, and perform all standard user actions including creating and running syncs.

Member
:   Can create, configure, and run syncs but cannot access the Administration page or manage other users.

Admins can toggle a member's role between Admin and Member using the role control on each row. Admins can also remove a member from the organization by clicking the remove button on the member's row.

**Important:** Removing a member immediately revokes their access to the Syndication Service. This action cannot be undone; you would need to send a new invitation to restore access.

## Invitations {#section_invitations .section}

The invitations table lists pending invitations that have been sent but not yet accepted. Each row shows the invited email address and the date the invitation was sent. From this table you can:

-   Copy the invitation link to share it directly with the invitee
-   Cancel a pending invitation to prevent it from being accepted

To invite a new member, click **Invite Member**. A dialog opens where you enter the invitee's email address and select their initial role.
