# Syncs List {#c_syncs_list .concept}

The Syncs list shows all sync configurations in your organization and provides the starting point for creating, viewing, and managing syncs.

Click **Syncs** in the navigation menu to open the Syncs list. Each row in the table represents one sync configuration and shows the following information:

Name
:   The descriptive name you assigned to the sync when you created it.

Source
:   The source system the sync reads content from. The source will always be the Heretto Deploy API, listed as "deploy."

Target
:   The target system the sync publishes content to, for example Salesforce Knowledge.

Schedule
:   The human-readable description of when the sync runs automatically, or Manual sync only if no automatic schedule is configured.

Status
:   Whether the sync is active or inactive.

Click any row to open the Sync Detail page for that sync. Click **New Sync** to create a new sync configuration.

**Note:**

This lists the Deployment ID and target UUID for reference.

**Tip:** If the list is empty, no syncs have been created yet. Click **New Sync** to set one up.
