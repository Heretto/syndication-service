# Delete a Sync {#t_delete_sync .task}

Permanently remove a sync configuration and its automatic schedule from the Syndication Service.

Deleting a sync removes its configuration and cancels any automatic schedule. Content that has already been published to the target system is not affected. This action cannot be undone.

1.  In the navigation menu, click **Syncs**.

2.  Click the name of the sync you want to delete.

    The Sync Detail page opens.

3.  Click **Delete**.

4.  In the confirmation dialog, confirm that you want to permanently delete the sync.

    The sync configuration and its schedule are permanently removed. You are redirected to the Syncs list.


The sync is deleted and no long available to use.

**Important:** Deleting a sync does not remove content that was previously published to the target system. To remove published articles, you must do so directly in the target system.
